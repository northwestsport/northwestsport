# NORTHWESTSPORT Travel & Tourism

A responsive white-and-green travel landing page, built with HTML, CSS and vanilla JavaScript.

## Deploy on GitHub Pages

1. Upload `index.html` and the `assets` folder to the root of your repository.
2. Go to Settings > Pages and choose Deploy from a branch, `main`, `/ (root)`.
3. Save and open the GitHub Pages URL once deployment completes.

## Important notes

- Sample packages and prices are illustrative only; no availability, accommodation, or ticketing is confirmed.
- The contact form is a **demo** and does not send messages or collect submissions. Connect your own backend/form provider before using it commercially.
- Remote Unsplash photographs require an internet connection. Image credits belong to the respective photographers/Unsplash; confirm appropriate licensing for commercial use.
